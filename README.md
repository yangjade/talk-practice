# 聽話說話練習

幫助長輩練習「聽懂完整的一句話」和「跟別人對話」的網頁。只有一個檔案 `index.html`，不用安裝、不用帳號。

## 安裝成 App

把整個資料夾放到網路上（例如 GitHub Pages、Netlify Drop），用手機的 Chrome 打開網址：

- **Android**：右上角「⋮」→「安裝應用程式」或「加到主畫面」。
- **iPhone**：用 Safari 打開 →「分享」→「加入主畫面」。

安裝後桌面會有「說話練習」圖示，沒有網路也能用。

## 怎麼使用

1. 用 **Chrome** 打開 `index.html`（手機、平板、電腦都可以）。
   - 放到網路上（例如 GitHub Pages、Netlify）後用網址打開，手機才能用麥克風。
2. 先到「家人設定」調整說話速度、字體大小和稱呼。

## 功能

- **聽懂練習**：唸一整句話，再一題一題問句子裡的每個重點（時間、地點、要做什麼）。答錯時會提醒「注意聽句子的前面／中間／後面」，最後用紅色標出漏聽的地方。分成一、二、三個重點三個等級。
- **跟著說**：聽完一句話後按麥克風複述，會標出哪些重點有說到、哪些漏掉了。
- **對話練習**：看醫生、接家人電話、跟鄰居打招呼、買菜等情境，可以用說的或用選的回答，並練習說「請再說一次」。
- **家人設定**：用家裡常講的話自己出題、查看練習紀錄。

資料只存在這台裝置的瀏覽器裡。
